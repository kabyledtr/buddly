# Buddly

Buddly organise les sorties entre amis : on crée un groupe via un lien d'invitation, chacun indique ses préférences (budget, quartier, distance, dispos, activités), puis tout le monde swipe des restos et activités réels à proximité. Quand tout le groupe dit oui, c'est un match. L'IA adapte les recommandations aux envies du groupe.

Projet construit pendant la **FounderRace** (21–22 novembre 2026). Thème : IA × relation humaine.

- Site : https://buddly.io
- Modèle : freemium (Gratuit / Premium 4,99 €/mois)

## Boilerplate

Projet initialisé avec le boilerplate public officiel **create-next-app** (Next.js 15, TypeScript, Tailwind CSS), ajouté par commit après le départ de la course.

## Lancer en local

```bash
npm install
npm run dev
```
